#### 🔍 System Design & Problem Solving
* **Administrative Scalability:** Solved the bottleneck of manual student tracking by building an **Automated Control Plane**. This reduced administrative overhead by 90%, allowing instructors to focus on curriculum advancement rather than registration logistics.
* **UX for the Modern Student:** Engineered a "Sanctuary UI" a distraction free dashboard mapping the four core disciplines: **ንባብ (Nibab)**, **ቅኔ (Qine)**, **ግእዝ (Ge'ez)**, and **ባህረ ሃሳብ (Bahre Hasab)**.
* **Optimized Onboarding:** Developed a localized payment visualization system to clarify one time registration vs. recurring tuition, featuring seamless "Copy to Clipboard" integrations for regional banking API constraints.

#### ⚙️ Technical Highlights
* **Latency Optimization:** Aggressive mobile optimization for fluctuating network speeds using PWA standards and lightweight data fetching schemas.
* **Heritage Driven Design:** Custom "Sage & Parchment" palette integrated with modern typographic hierarchy to maintain cultural authenticity within a digital framework.
